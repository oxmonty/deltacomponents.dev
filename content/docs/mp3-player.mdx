## Usage

```tsx
import { MP3Player } from "@/components/ui/mp3-player";

<MP3Player src="/audio/track.mp3" title="Track Name" artist="Artist Name" />
```

## Waveform

<ComponentPreview name="mp3-player-waveform" />

`peaks` are 0–1 values you compute ahead of time, e.g. with ffmpeg. When the player is too narrow to draw one bar per value, neighbouring peaks merge and the loudest one wins.

## Composition

The default layout is `MP3Player` rendering its parts for you. Pass children to arrange them yourself:

```tsx
import {
  MP3Player,
  MP3PlayerPlay,
  MP3PlayerTime,
  MP3PlayerScrubber,
  MP3PlayerSpeed,
  MP3PlayerDownload,
} from "@/components/ui/mp3-player";

<MP3Player src="/audio/track.mp3">
  <MP3PlayerPlay />
  <MP3PlayerTime />
  <MP3PlayerScrubber className="flex-1" />
  <MP3PlayerTime remaining />
  <MP3PlayerSpeed />
  <MP3PlayerDownload />
</MP3Player>
```
