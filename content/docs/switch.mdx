## Usage

```tsx
import { Switch } from "@/components/ui/switch";

<Switch defaultChecked />
```

It is Base UI's Switch underneath, so it carries the `switch` role, full
keyboard support, and a form `name`/`value` for free. The thumb's travel is a
keyframe sequence that plays only on a change, never on mount.

## Sizes

`sm` is Ant Design's small switch (28×16), the default its 44×22, and `lg` the
default at iOS's 51×31 proportion. The thumb is iOS 26's at every step: a wide
pill filling most of the track's height behind a thin inset.

## Override Styling

Every size is a handful of CSS variables on the root, so a `style` can set a
geometry of its own and the travel, hover pill and press squash follow:

| Variable | Default | Meaning |
| --- | --- | --- |
| `--switch-w` | `44px` | Track width |
| `--switch-h` | `22px` | Track height |
| `--switch-pad` | `2px` | Inset between track and resting thumb |
| `--switch-thumb-w` | `26px` | Resting thumb width |
| `--switch-thumb-h` | `18px` | Resting thumb height |
| `--switch-pill` | `2px` | Extra width the thumb gains on hover |
| `--switch-press` | `4px` | Extra width (and matching squash) on press |
| `--switch-overshoot` | `1px` | How far the bounce overshoots the end |

Parts you hold no reference to are reachable by `data-slot`:

| Slot | Element |
| --- | --- |
| `switch` | The track, a `span` with the `switch` role |
| `switch-thumb` | The sliding thumb |
