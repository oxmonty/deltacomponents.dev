The icon isn't drawn on top of the shape in a matching color — it's cut out
of it with an SVG `mask`, leaving a genuine hole. Painting the icon white (or
whatever the surrounding background happens to be) only works on a flat card;
the moment the badge sits over a photo or a gradient, the paint seams. A real
hole never does, because there's nothing to match.

Glyph only owns the shape. The icon is whatever element you pass as
`children` — lucide, phosphor, a hand-rolled `<svg>` — as long as it colors
itself with `currentColor`, which is the default for nearly every icon
library.

## Usage

```tsx
import { Check } from "lucide-react";
import { Glyph } from "@/components/ui/glyph";

<Glyph mask="rosette" className="text-[#1d9bf0]">
  <Check />
</Glyph>
```

## Sizes

Size is a `className`, the same as a lucide icon — pass `size-*` (or
`h-*`/`w-*`) and the shape scales with it.

<ComponentPreview name="glyph-sizes" />

## Accessible label

<ComponentPreview name="glyph-label" />

By default the badge is `aria-hidden` — it's meant to sit beside a name or
title that already announces "verified". Pass `label` to announce it instead,
which switches the badge to `role="img"` with an `<svg><title>`.
