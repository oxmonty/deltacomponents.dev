This registry is maintained by me, [Patrick Prunty](https://patrickprunty.com), for my own use cases. It isn't a general-purpose component library and doesn't aim to be one. A component gets in when I've needed it across multiple projects and found it difficult enough to build on more than one occasion.

The license is [MIT](https://github.com/oxmonty/deltacomponents.dev/blob/main/LICENSE), so you're free to use any of these components however you like. What I ask in return is a favour rather than a requirement: tell me what worked and what didn't. If you find a way to generalise one of these components to a more pressing product use case, share the details so we can refine it together within this registry. Those contributions make the component better for everyone who uses it, including me.

## What I accept and what I don't

If it's already done well by [Base UI](https://base-ui.com) or [shadcn](https://ui.shadcn.com), I don't want it. Unless yours is a considerable improvement in API or design, please don't bother.

## How to contribute

Reach out to me via [email](mailto:patrickprunty.business@gmail.com) or [X](https://x.com/pprunty_), or [open an issue](https://github.com/oxmonty/deltacomponents.dev/issues) before a pull request for anything beyond a small fix. It saves us both time if we agree on the shape of a change first.

For local development:

```bash
make run
```

That installs dependencies and starts the dev server. `make check` runs what CI runs, and `make` on its own lists every target.
